EXPLORE GitHub PR reviews and THINK whether some or all of them should be implemented:

Follow these steps:

1. Use `gh pr view --json reviews` to get all review comments for the current branch's PR
2. For each review comment, understand the feedback and locate the relevant file/line
3. Implement the requested changes following CLAUDE.md code style
4. Write and run tests to verify the changes
5. Ensure code passes linting and type checking

Remember to use the GitHub CLI (`gh`) for all GitHub-related tasks.
